# AI Agricultural Policy Forecasting System

An AI-based decision support system that predicts the impact of agricultural policies and environmental conditions on crop yield, farmer income, and water usage.

## Overview
This system allows users to simulate different policy scenarios such as fertilizer subsidy, MSP changes, rainfall variation, and temperature conditions. It uses machine learning models to generate predictions and provides AI-generated insights for better policy decision-making.

## Features
- Crop yield prediction using ML models
- Farmer income and water usage estimation
- Policy scenario simulation (what-if analysis)
- Baseline vs simulated comparison
- AI-generated policy insights and recommendations

## Tech Stack
- Python
- Streamlit
- XGBoost
- Scikit-learn
- Pandas, NumPy
- HuggingFace (LLM)

## Usage
Run the application:streamlit run app.py


## Outcome
Helps policymakers evaluate agricultural policies before implementation to improve food security and sustainability.
